01执行摘要

BioJING 当前功能完整：52 篇系列博文展示、搜索、评论、资源下载与管理后台均已实现，选型与内容规模匹配，代码约 1,800 行、结构清晰。但实测确认它尚不具备公网长期运行条件，核心结论四条：

  • 高危漏洞可直接利用（P0）：管理页面有密码保护，但全部管理 API 无服务端校验。本地实证：不带凭证 GET /api/admin/posts 返回 200、POST 成功建文（自检数据已清理）。任何人可绕过后台增删文章、上传文件。
  • 公开版一度无法生产构建（P1，已修复）：tsconfig.json 缺 target 致 next build 报 TS2802；本次已修复并复验通过。根因是缺少 CI 门禁。
  • 三处功能性缺陷：Mermaid 图表从未加载渲染；Markdown 经 rehype-raw 直出未净化（存储型 XSS 面）；评论默认直接公开，后台审核形同虚设。
  • 增长与运维缺位：全站强制动态渲染、无 sitemap/RSS/OG；备份无恢复与校验；测试仅 3 个耦合本地状态的 pytest，无 CI、无 lint、无容器化。
本次已落地：Cursor Agent 开发环境（.cursor/environment.json、幂等 install/start 脚本、三份项目规则、AGENTS.md）与生产构建修复；云端环境已完成草案构建验证并提案，待在环境面板保存。业务功能与数据库结构本次未动。

技术基线

  • 单体 Next.js 14.2 + React 18.3 + Prisma 5.14 + SQLite，Tailwind 3.4；依赖均已落后主流大版本，npm audit 报 7 个漏洞（1 critical、4 high）。
  • 数据模型 10 个：状态字段为裸字符串无枚举约束，高频查询字段无索引，User 模型与 bcryptjs 全仓未使用。
  • next.config.js 埋有未触发地雷：raw-loader 规则与 sharp 声明均无对应已装依赖；图床为 https + ** 通配。
  • 端口 dev/start 固定 30001，符合避开 3000/8000 约定，登记保留。

05发布门禁与风险

  • 数据库：任何 schema/数据变更先备份并校验落盘，再在副本演练，最后执行；发布说明写明备份文件与回滚命令。
  • 安全：新增 API 必须声明鉴权与入参校验；上传/Markdown/认证改动必须附未授权与恶意输入回归用例。
  • 测试：新功能附正常/边界/失败三类测试；合并前 typecheck、lint、build 与相关测试全绿；页面改动附桌面+手机验收。
  • 回滚：每版保留上一构建与库备份；无迁移版本直接回退代码，有迁移版本先恢复库备份。
